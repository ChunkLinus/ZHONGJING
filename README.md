# 仲景模拟器 (Zhongjing Simulator) —— 使用指南

这是一套基于《Glyphica》游戏重构的“伤寒论”考试强化推演系统。通过极速键入条文拼音，旨在锻炼对条文的瞬间反应与肌肉记忆。

## 1. 战术部署协议（关键步骤）

1. **物理环境隔离**：将压缩包全量解压至本地非中文路径下。
2. **初次点火（生成目录）**：双击运行根目录下的 `start.bat`（或 `neosphere.exe`），进入游戏主菜单后直接退出。此动作将强制引擎在系统盘建立持久化存储目录。
3. **题库覆写（注入模组）**：打开系统的文档目录，精准导航至：
   `Documents\Sphere Saves\aliasblack.glyphica\mods\`
   将压缩包内提供的 `shanghan_lun.json` 文件，直接覆盖掉该目录下刚刚由系统自动生成的同名文件。
4. **二次点火**：重新启动游戏，即可进入实战。

## 2. 物理共存警告 (System Override Warning)

如果你的本机已经安装了《Glyphica》的 Steam 正版，**正版客户端与本模拟器将强制共用上述 `Sphere Saves` 模组文件夹**。
这意味着题库的覆写将对正版游戏同时生效。如需恢复正版纯净环境，需手动清空该 `mods` 文件夹。

## 3. 自主命题与操作语法

* **输入法则**：底层核心已锁定，实战推演中**仅支持中文拼音输入**。请确保输入法处于英文状态（或大写锁定），游戏时建议开启美式键盘，面对目标直接敲击汉字全拼，无须输入标点符号。
* **挖空规则**：使用纯文本编辑器（如记事本、VS Code）打开 `shanghan_lun.json`。将需要设为考点的词汇用英文大括号 `{}` 包裹。系统将自动把大括号内的内容生成为实体怪物。
  *例：`"太阳病，头痛，发热，汗出，恶风，{桂枝汤}主之。"`*

## 4. 引擎底层参数（开发者选项）

具备基础代码阅读能力的同学，可通过编辑 `scripts/core/` 目录下的源码文件直接篡改底层参数：

* **战场压迫感（刷怪倍率）**：
  * **路径**：`scripts/core/global.js`
  * **参数**：搜索 `global.shanghanSpawnMultiplier = 3.0`
  * **说明**：调高（如 `5.0`）将减速，提供背诵时间；调低（如 `0.1`）将解除引擎的同屏容量锁，激活高压弹幕模式。
* **绝对防御（锁血模式）**：
  * **路径**：`scripts/core/console.js`
  * **参数**：搜索 `global.immortal = false` 并改为 `true`
* **军费配给（初始资金）**：
  * **路径**：`scripts/core/loader.js`
  * **说明**：引擎已在 `loadGame()` 函数中硬编码注入了 `save.coins = 9999999`，进入游戏即可无视成本解锁全战术流派。
* **自动化算力测试**：
  * **路径**：`scripts/core/global.js`
  * **参数**：搜索 `global.wpmSimulator = 0` 并改为 `300`
  * **说明**：开启后，引擎将接管输入流，以 300 WPM 的极速自动锁敌并肃清屏幕，可用于题库稳定性压测。
