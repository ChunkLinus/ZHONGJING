# 仲景模拟器 (Zhongjing Simulator) v1.0

欢迎使用《仲景模拟器》。这是一个专门为中医学生和从业者设计的背诵打字游戏。通过快速敲击拼音，帮助大家建立对《伤寒论》等中医临床典籍的肌肉记忆与方证条件反射。

## 1. 快速开始 (安装与运行)

* **文件解压**：请将下载的压缩包解压到一个**没有中文字符**的文件路径下。
* [cite_start]**脱离 Steam 运行**：本游戏已完全去除了对 Steam 平台的依赖，是一款 100% 的纯净单机软件 [cite: 183][cite_start]。无论你电脑上有没有打开 Steam，都不会闪退或报错 [cite: 183]。
* [cite_start]**启动游戏**：直接双击文件夹里的 `start.bat`，就可以打开游戏了 [cite: 183]。

## 2. 题库与模组自定义

[cite_start]游戏支持你无限添加自己整理的题库 [cite: 184]。

* [cite_start]**文件存放位置**：所有的题库文件（.json 格式）都必须放在游戏文件夹里的 `mods` 文件夹中 [cite: 184]。
* [cite_start]**自动识别**：只要把符合格式的 `.json` 文件放进去，游戏每次启动时都会自动读取 [cite: 184][cite_start]。文件的名字（比如“金匮要略.json”、“温病条辨.json”）会自动变成游戏设置菜单里的切换按钮 [cite: 184]。
* [cite_start]**题目怎么写**：你可以用任何文本编辑器（vs code、记事本等等）打开这些 json 文件。在经文里，把你想要作为“填空题”考点的词，用英文的大括号 `{}` 包起来 [cite: 184][cite_start]。游戏会自动把这些词变成需要你打拼音消灭的怪物 [cite: 184]。

## 3. 游戏玩法说明

* [cite_start]**拼音输入法**：游戏底层经过修改，**只支持中文全拼输入** [cite: 184][cite_start]。玩的时候，推荐把电脑输入法切换到美式键盘，然后直接按目标汉字的全拼字母即可 [cite: 184]。
* [cite_start]**打字定身机制**：当屏幕上有很多词向你靠近时，只要你打对了某个词的第一个字母，这个词就会立刻停在原地不动，方便你把它打完 [cite: 184][cite_start]。但请注意，屏幕上其他没被你打到的词，还是会继续以原来的速度向你靠近 [cite: 184]。

## 4. 游戏速度与难度调整

如果你觉得游戏太快跟不上，或者太慢没挑战，可以使用文本编辑器打开 `scripts/core/global.js` 文件来调整难度：

* [cite_start]**出怪速度**：在代码里找到 `spawnConfig.globalMultiplier` 这个参数 [cite: 185]。
    * 默认设置是 `1.0`。
    * [cite_start]如果想**变慢**：把数字改大（比如改成 `2.0`），怪物出现的间隔时间就会翻倍，适合初期背诵 [cite: 185]。
    * [cite_start]如果想**变快**：把数字改小（比如 `0.5` 或 `0.1`），怪物会像潮水一样疯狂涌出，适合挑战极限 [cite: 185]。
* [cite_start]**同屏怪物上限**：找到 `spawnConfig.maxConcurrent` 这个参数。它决定了屏幕上最多能同时存在多少个词（默认是 50） [cite: 185][cite_start]。如果屏幕上的词达到了这个数字，游戏就会暂停出新词，直到你打掉几个腾出空间，这样可以防止电脑卡顿 [cite: 185]。
